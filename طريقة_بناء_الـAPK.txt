مشروع أندرويد الأصلي الكامل — مواقيت الصلاة والأذكار
======================================================

هذا المجلد هو مشروع Android Studio متكامل وجاهز للفتح والبناء مباشرة بدون أي تعديل يدوي على الملفات.

لماذا لا يشتغل إشعار النظام عبر موقع freehtmltoapk؟
- موقع freehtmltoapk يحوّل ملف HTML فقط ولا يبني كود Kotlin أو AlarmManager في النظام.
- لبناء APK يحتوي على كود أندرويد الأصلي الذي كتبناه لك، يجب تجميع هذا المشروع كـ APK.

طريقة تحويل هذا المشروع إلى ملف APK:
الطريقة الأولى (على اللابتوب عبر Android Studio):
1. فك الضغط عن ملف MawaqitAndroidFullProject.zip.
2. افتح برنامج Android Studio واختر Open ثم اختر مجلد MawaqitAndroidFullProject.
3. انتظر حتى ينتهي Gradle Sync.
4. من القائمة العلوية اختر: Build -> Build Bundle(s) / APK(s) -> Build APK(s).
5. سينتج لك ملف app-debug.apk جاهز للتثبيت على الهاتف، وعند الضغط على "تجربة إشعار" أو دخول وقت الصلاة سيظهر إشعار حقيقي في شريط إشعارات النظام خارج التطبيق.

الطريقة الثانية (بدون تثبيت Android Studio — عبر GitHub Actions مجاناً):
1. ارفع محتويات هذا المجلد إلى مستودع على GitHub.
2. شغّل Gradle build (./gradlew assembleDebug) ليخرج لك ملف APK جاهز للتحميل على هاتفك.
